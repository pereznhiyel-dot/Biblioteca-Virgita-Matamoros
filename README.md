# Biblioteca virtual
Esta es una página para la biblioteca del colegio, esta tiene fusiones para poder ver videos educativos, leer, y jugar juegos de mesa, esta tiene un control bastante estricto a la hora de iniciar como profesor y uno bastante simple para los estudiantes.

# ¿Como accedo como profesor?
primero tienes que mandar un correo al Gmail de la biblioteca: bibliotecavirgita@gmail.com.

Para que pueda ser añadido nos tienes que enviar estos datos: el correo GMAIL que vas a usar y la contraseña
>se prefiere que el correo sea del mep de profesores, ya que los normales tendran que ser revisados con mas tiempo

>La contraseña tiene que ser una fuerte, con minúsculas, mayúsculas y caracteres especiales: "#$$&@"?¿¿"

# Usar los paneles de profesor
Los profesores tienen acceso a configuraciones que los estudiantes no tiene acceso, entre los poderes del profesor se encuentra, añadir, modificar, eliminar y aceptar el contenido de la pagina

>editar: Aqui se puede editar los enlaces, nombres, imagenes, juegos y videos de la pagina

>modificar: Aqui se puede modificar los enlaces, nombres, imagenes, juegos y videos de la pagina

>eliminar: en este se tendrá que tener precaución a la hora de elegir la información a borrar

>cuando un profesor accede o pide crear una cuenta automáticamente podrá ver y modificar, pero si alguno borrar información importante o abusa de su poder se le arrebatará el acceso completo como profesor impidiendo que pueda acceder como un profesor y a la vez quitándole el acceso a las configuraciones

aceptar contenido: los estudiantes tienen un panel donde podrán pedir nuevas lecturas, videos o juegos y los profesores tienen un panel donde van a llegar esas solicitudes, los profesores tendrán que revisar los LIKS para evitar el contenido para adulto, si un profesor añadió un contenido sin revisarlo se le tendrá que dar su respectiva sanción
